# Guitar Chord Trainer

A lightweight, browser-based application designed to help guitarists practice chord transitions and build muscle memory. Set your BPM, choose your chord group or song progression, and play along!

## Features

*   **Dynamic SVG Diagrams:** Chord diagrams and finger placements are generated programmatically via JavaScript—no external image files required.
*   **Built-in Metronome:** Utilizes the browser's native Web Audio API to generate accurate, customizable click tracks (Standard, Woodblock, or Synth).
*   **Adjustable BPM:** Control your practice speed on the fly with a slider (1-200 BPM) without interrupting the flow.
*   **Smart Randomization:** Random practice modes ensure the same chord never plays twice in a row.
*   **Song Progressions:** Practice real-world transitions with sequential modes covering popular progressions (Pop 4-Chord, 50s Ballad, Classic Rock, Alt-Rock).

## Built With

*   HTML5
*   CSS3 (Modern UI with CSS Variables and custom range sliders)
*   Vanilla JavaScript (ES6+)
*   Web Audio API
*   *Zero external libraries, frameworks, or dependencies.*

## Getting Started

Because this is a completely vanilla, single-file application, there is no build process or package installation required.

1. Clone the repository or download the files.
2. Open `index.html` in any modern web browser.
3. Click "Start" and begin practicing!
